  [fizika](https://longouz.vercel.app/fanlar/fizika)

- IELTS Reading, Writing, Speaking mashqlari
- Natijalar tahlili va QR kodli sertifikatlar
- Bepul tarif; Pro — 25 000 so'm/oy, Ultra — 40 000 so'm/oy
